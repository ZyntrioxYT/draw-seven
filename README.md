# Draw Seven

A polished, dependency-free browser card game inspired by the push-your-luck rules of Flip 7. Play solo against three computer rivals, collect unique numbers, use action cards, and race to 200 points.

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

Push these files to the repository's default branch, then open **Settings → Pages** on GitHub. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

No build command is required.
